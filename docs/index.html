About these diffs

New York magazine never published a list of the remediated articles. It did, however, append the same sentence to every article it corrected — “August 14, 2026: A previous version of this article did not meet New York’s editorial standards. It has been updated to include appropriate attribution.” Search the Ross Barkan archive at nymag.com for that sentence and you have the 67.

Original text in each diff is taken from each article's earliest usable Wayback Machine snapshot; updated text is the article as it stood on nymag.com when we last ran the scraper script to populate this page on August 30, 2026.

Because the correction notice is the same sentence in every case, it's not shown as a change in the diffs above.
