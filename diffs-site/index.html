About these diffs

New York never published a list. It did, however, append the same sentence to every article it corrected — “August 14, 2026: A previous version of this article did not meet New York’s editorial standards. It has been updated to include appropriate attribution.” That uniformity is what makes the set identifiable: search the archive for the sentence and you have the 67.

Because it is the same sentence in every case, it is not shown as a change above.

Original text is each article’s earliest Wayback Machine snapshot; updated text is the live page. The hyperlinks shown are the URLs as published: none of the 684 links in this data carry the archive’s own rewriting.
